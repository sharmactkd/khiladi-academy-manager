USAGE
1. Start backend and frontend normally.
2. Open Data Management > Imports.
3. Choose Ground(5).xlsx.
4. Enable "Temporary Ground.xlsx recovery".
5. Select the correct destination branch and batch, then Analyse.
6. Confirm every repeated name as Same student or Different students.
7. Resolve unmatched identities, then click Run comparison in Excel recovery audit.
8. Review missing student records, missing months, partial months, missing dates, metadata gaps and protected conflicts.
9. Only the current year's September tile is disabled. Older years' September records remain importable. Existing profile values and attendance marks are preserved; only blank profile fields, missing marks, and blank month metadata are filled.
10. Import only the selected players, then review result counts and errors before removing this temporary feature.
11. Unchecked name/spelling variants are treated as intentionally skipped and do not block Continue.
