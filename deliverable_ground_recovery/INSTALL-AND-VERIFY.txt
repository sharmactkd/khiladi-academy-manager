USAGE
1. Start backend and frontend normally.
2. Open Data Management > Imports.
3. Choose Ground(5).xlsx.
4. Enable "Temporary Ground.xlsx recovery".
5. Select the correct destination branch and batch, then Analyse.
6. Confirm every repeated name as Same student or Different students.
7. Resolve unmatched identities, then click Run comparison in Excel recovery audit.
8. Review missing student records, missing months, partial months, missing dates, metadata gaps and protected conflicts.
9. Only the current year's September tile is disabled. Older years' September records remain importable. Existing profile values and attendance marks are preserved; only blank profile fields, missing marks, and blank month metadata are filled.
10. Import only the selected players, then review result counts and errors before removing this temporary feature.
11. Unchecked name/spelling variants are treated as intentionally skipped and do not block Continue.
12. Pending or unconfirmed identities are safely skipped when other resolved attendance or metadata selections are ready to import.
13. The current month in attendance history uses the same live membership fee balance as the attendance table; older imported months remain unchanged.
14. PDF, Print and Excel each support complete history, an inclusive month range, a particular year or a particular month, independent of screen pagination.
15. PDF and Print use the same year-wise colored attendance layout as the screen; Excel mirrors the same grouped structure and status colors.
16. "Custom date range" uses Start month and End month. Search another student directly from the attendance-history page by name, phone or admission number.
17. Attendance-history search displays students' first, middle and last names instead of the generic "Student" label.
18. Membership Control uses accessible category tiles and contextual sub-actions instead of the long adjustment dropdown.
