USAGE
1. Start backend and frontend normally.
2. Open Data Management > Imports.
3. Choose Ground(5).xlsx.
4. Enable "Temporary Ground.xlsx recovery".
5. Select the correct destination branch and batch, then Analyse.
6. Review every unresolved identity. Do not create a new student when the app already has that person; link it manually.
7. September tiles are disabled. Existing profile values and attendance marks are preserved; only blank profile fields, missing marks, and blank month metadata are filled.
8. Confirm the preview, then import. Review the result counts and errors before removing this temporary feature.
