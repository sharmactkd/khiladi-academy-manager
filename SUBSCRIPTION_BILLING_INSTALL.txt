KHILADI SUBSCRIPTION & BILLING HUB

Run from repository root in VS Code PowerShell.

1. Extract:

Expand-Archive `
  -Path ".\khiladi-subscription-billing-complete-code.zip" `
  -DestinationPath "." `
  -Force

2. Remove legacy pages replaced by the hub:

git rm --ignore-unmatch `
  frontend/src/pages/plans/Plans.jsx `
  frontend/src/pages/billing/BillingDashboard.jsx `
  frontend/src/pages/billing/Invoices.jsx `
  frontend/src/pages/billing/PaymentHistory.jsx

3. Clear Vite cache and verify:

Remove-Item -Recurse -Force frontend\node_modules\.vite -ErrorAction SilentlyContinue
npm run build --prefix frontend
git status --short

Do not delete Checkout.jsx, PaymentSuccess.jsx, PaymentFailed.jsx,
InvoiceDetail.jsx or InvoicePreview.jsx. They remain focused transactional flows.
